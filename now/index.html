What I'm Working On

Last updated: Nov 2026

Outside of my day job I keep a home lab running, and most of my personal projects grow out of it. This page is a snapshot of what currently has my attention, rather than a finished write-up of it. Of everything on this site it is the page that changes most often.

Right now that means two things that are really one project: an AI assistant I host myself, and the server it lives on.

A Self-Hosted AI Assistant

Hermes is an AI agent I run on my own hardware instead of paying for a hosted service. I can reach it from any device on my local network, as well as from my phone through Telegram, and it can read and write files, run shell commands, search the web, and drive a browser. That makes it feel less like a chat window I ask questions to and more like a teammate I can work with.

  • Conversational access: I message it the way I would message a coworker. It keeps context across a conversation and stores standing preferences in a persistent memory file, so I don't have to restate how I like things done.
  • Scheduled work: a few jobs run on their own schedule, including a weekly OS update check that reports what it found before applying patches, a periodic cleanup of old session data, and a daily technology news digest delivered to my phone.
  • Tools: it searches through a self-hosted SearXNG instance, reads pages with a real browser rather than a scraper, and works with Git and the GitHub CLI, so it can open issues and pull requests the same way I do.
  • Reusable procedures: instructions for recurring tasks live in small skill files that the agent loads when a matching task comes up. An update routine or a change to this site then runs the same way every time instead of being worked out from scratch.

The interesting part isn't the model, it's the engineering around it: permissions, scheduled jobs, and keeping an agent with shell access pointed at the things it should touch and nothing else.

The Server Behind It

All of it runs on one mini PC-turned-server: an AMD Ryzen 7 6800U with 24 GB of RAM running Ubuntu. Staying on a single machine keeps the whole setup cheap and gives me one place to patch, back up, and reason about. It works a second job as my DNS and media box.

Services & Tools

  • Docker

    Every service runs in its own container, defined by a Compose file, so I can rebuild or replace one without disturbing the rest of the machine.

  • Ubuntu

    The host operating system. Security updates install unattended on a weekly schedule, and the machine reboots itself afterward.

  • Pi-hole

    Network-wide DNS filtering, so ad and tracker domains are blocked for every device on the network without configuring each one.

  • Jellyfin

    My own media server. It streams the films and shows I already own to the TV, phone, and browser, with no subscription involved.

  • SearXNG

    A self-hosted search instance. The agent's web searches go through it rather than a commercial API, so queries aren't tied to an account.

  • Tailscale

    A private mesh network that makes the server reachable from my phone and laptop while I'm away from home, without opening a port to the internet.

  • Hermes

    The agent itself: a service that connects the assistant to my files, the shell, a browser, and Telegram, and runs the scheduled jobs.

  • Ollama

    Runs language models locally on the CPU, so smaller tasks stay on my own hardware instead of going out to a hosted API.

Everything is defined in Docker Compose files, so a service is a configuration change rather than a manual install. Nothing is exposed to the public internet: remote access goes through a private mesh network, and each service serves HTTPS from a locally issued certificate authority I trust on my own devices.

Keeping it healthy is its own project. Updates install unattended on a weekly schedule and the machine reboots itself afterward, which only works because the update routine reports back over Telegram before it goes down. Local models run on CPU, so I keep them small and the context window modest; working out where that ceiling actually sits is an ongoing experiment.
